# 抹茶日和 オーディオ素材の配置

このフォルダに **ライセンスを確認できる音源のみ** を配置してください。
ファイルが存在する場合は自動的に読み込まれ、無い場合は手続き生成の
仮サウンド（プレースホルダ）が使われます（ゲームは停止しません）。

> ⚠️ 現状、正式音源は未配置です。現在はすべて仮サウンドで動作しています。
> 「追加完了」ではなく「仮サウンドで動作確認済み・正式音源待ち」の状態です。

## 必要なファイル

| 種別 | パス | 内容 | ループ |
|---|---|---|---|
| BGM | `public/audio/bgm/koto_calm.ogg` | 「静寂の茶室」: 疎な琴＋控えめな尺八の静かな和風アンビエント（60〜120秒ループ）。制作手順は [BGM_PROMPT.md](./BGM_PROMPT.md) を参照。 | 必須（シームレス） |
| 環境音 | `public/audio/ambient/tearoom.ogg` | かすかな鳥のさえずり・風・茶室の空気感。 | 必須（シームレス） |

- 参照パスは `src/audio/GameMusic.ts` の `AUDIO_ASSETS` で定義しています。
- フォーマットは `.ogg` を想定（必要なら `.mp3` 等へ変更し `AUDIO_ASSETS` を更新）。
- BGM と環境音は別チャンネルで、`AudioManager.setBgmVolume` / `setAmbientVolume`
  により **個別に音量調整** できます（既定: BGM 35% / 環境音 50% / 効果音 75%）。
- ループは末尾と先頭が自然につながる素材にしてください。

## ライセンスについて（重要）

- 使用する音源は、商用/非商用の利用条件・クレジット要否・改変可否を
  **必ず確認**してください（CC0 / CC-BY / 購入ライセンス等）。
- CC-BY など帰属表示が必要な場合は、このフォルダに `CREDITS.md` を追加し、
  作者名・曲名・ライセンス・入手元 URL を明記してください。
- 条件が確認できない音源は使用しないでください。

## 仮サウンドについて

正式音源が配置されるまで、以下を Web Audio で手続き生成しています
（`src/audio/musicBuffers.ts`）。あくまで動作確認用の暫定音です。

- BGM: 琴風ペンタトニックの撥弦ループ
- 環境音: 風のうなり＋ときどき鳥のさえずり＋薄い空気感
